Code review

- [How the Claude Code team does code review](https://claude.dev/blog/solving-code-review-at-anthropic/). Claude writes the code, and reverts went down anyway.
- [AI agent fixed the bug, but what else did it change?](https://blog.trailofbits.com/2026/10/21/your-ai-agent-fixed-the-bug-but-what-else-did-it-change/) Agents fix bugs and quietly break other things.
